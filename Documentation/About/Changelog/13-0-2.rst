===========================
Version 13.0.2 - 2026-10-15
===========================

This is a maintenance release.

Download
========

Download this version from the `TYPO3 extension repository <https://extensions.typo3.org/extension/mautic/>`__ or from
`GitHub <https://github.com/mautic/mautic-typo3/releases/tag/v13.0.2>`__.

Announcement
============

Without the TYPO3 form framework (``EXT:form``) installed, the extension throws an exception and the system
does not work properly. As a temporary workaround, ``typo3/cms-form`` is now a required dependency. It will
become optional again once this bug has been fixed.

Changed
=======

* Add TYPO3 Forms (``typo3/cms-form``) as a required dependency for the time being, see announcement above

Fixed
=====

* Ensure compatibility with PHP 8.5
