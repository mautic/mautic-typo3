===========================
Version 13.1.0 - 2026-11-27
===========================

This is a feature release.

Download
========

Download this version from the `TYPO3 extension repository <https://extensions.typo3.org/extension/mautic/>`__ or from
`GitHub <https://github.com/mautic/mautic-typo3/releases/tag/v13.1.0>`__.

Added
=====

* New option ``timeout`` limits every request to Mautic to the given number of seconds (default ``5``). It can be set
  in the new "misc" tab of the backend module, see :ref:`Installation <installation>` for details

Changed
=======

* An unreachable Mautic instance no longer blocks the rendering of uncached pages: once a request has timed out, all
  further requests to Mautic within the same page request fail immediately and the page is delivered without Mautic
  content
* Each failed request to Mautic is logged exactly once

Fixed
=====

* Request bodies are forwarded to Mautic as a stream, so large asset uploads are no longer held in memory completely
